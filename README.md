# Angular: De Cero a Experto 🚀

Este repositorio contiene los proyectos prácticos, ejercicios y desafíos desarrollados a lo largo de las secciones básicas e intermedias del curso **Angular: De cero a experto** de Fernando Herrera en DevTalles.

El objetivo de este repositorio es consolidar el aprendizaje de las bases de Angular, TypeScript, servicios, directivas, enrutamiento, pipes personalizados, formularios reactivos y mapas en la web.

---

## 📁 Contenido del Repositorio

*   **`01-typescript-intro`**: Introducción y bases de TypeScript aplicadas a Angular.
*   **`02-bases`**: Conceptos fundamentales de Angular (componentes, directivas estructurales y de atributos).
*   **`03-gifs-app`**: Aplicación de búsqueda y almacenamiento de GIFs consumiendo la API de Giphy.
*   **`04-country-app`**: Buscador de países por capital, nombre y región, implementando rutas y debouncing con RxJS.
*   **`05-pipes-app`**: Uso y creación de Pipes personalizados para transformar datos en las plantillas.
*   **`06-reactive-forms-app`**: Creación de formularios complejos utilizando Reactive Forms y validaciones personalizadas.
*   **`07-lifecycle-hooks`**: Demostración y uso práctico de los ciclos de vida de los componentes en Angular.
*   **`08-maps-app`**: Integración de mapas interactivos utilizando Leaflet y servicios de geolocalización.
